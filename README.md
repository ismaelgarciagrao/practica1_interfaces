# Prototipo Polestar — Práctica 1 de Interfaces de Usuario (UMH)

Prototipo de aplicación de escritorio WPF (Microsoft Blend) para la venta de vehículos Polestar en
concesionarios: pantalla de **Inicio** (campaña, novedades y mejor precio), **Galería** de modelos y
**Acceso** de clientes.

- Abrir `PolestarPrototipo.sln` en Blend o Visual Studio y ejecutar con F5 (requiere .NET 8 o posterior).
- Cuenta de demostración: `cliente@polestar.es` / `Polestar2026`.
- Documentación: [`docs/DOCUMENTACION.md`](docs/DOCUMENTACION.md) · Registro de IA: [`docs/registro-ia.md`](docs/registro-ia.md)

| Fichero | Qué contiene |
|---|---|
| `PolestarPrototipo/MainWindow.xaml` | Toda la interfaz: cabecera, las 3 pantallas, pie y animaciones |
| `PolestarPrototipo/MainWindow.xaml.cs` | El código: cambiar de pantalla e iniciar sesión |
| `PolestarPrototipo/App.xaml` | Colores y estilos comunes |
| `PolestarPrototipo/Imagenes/` | Logotipo y dibujos de los coches |
| `docs/DOCUMENTACION.md` | Documentación de la práctica (también en PDF en la entrega) |
| `docs/registro-ia.md` | Registro del uso de inteligencia artificial |
| `herramientas/` | Scripts de comprobación (Python, opcionales) |

> El logotipo, las imágenes, los precios y los datos son **provisionales e ilustrativos**; no son material
> oficial de Polestar.
